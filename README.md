Need to load the CT table into Cheat Engine first.

The CT table contains a script that does paper check for you. Instructions will be printed once the script is enabled.

As written in the instructions, to let the script make a fact check, just stamp "approved" on the passport (which can be overwritten by "denied" later). You'll understand how it works after a few tries.

v1.4.11.124-S is the latest version by now. Other versions are not tested.
